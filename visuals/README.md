# Visuals for the map review

Screenshots from the final prototype builds, posted on [Docs Site for Plank Packages](https://github.com/plank/docs/issues/1) so design and front-end can review the map before the spec is written. This branch holds only these images, and it never merges.

They come from production builds (`astro build`) of two throwaway prototype branches, at 1440×900 and 2× (phones at 390×844 and 3×), in headless Chrome:

- **`prototype/code-blocks`**: landing page B and doc page A from [What do the landing page and a doc page look like?](https://github.com/plank/docs/issues/7), the Ink dark mode from [Does the Docs Site have a dark mode, and what does it look like?](https://github.com/plank/docs/issues/19), and the Sand card code blocks from [How do code blocks look, and which syntax theme do they use?](https://github.com/plank/docs/issues/25). Files 01–10.
- **`prototype/motion`**: motion C and plank.co's reduced-motion controls from [What moves on the Docs Site, and how does it respect reduced motion?](https://github.com/plank/docs/issues/22). It still has #7's first dark palette and code colours. Files 11–13.
